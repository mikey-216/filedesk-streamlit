# 📁 FileDesk — Streamlit File Management System

A modern file management application built with **Python** and **Streamlit**.

FileDesk provides a clean and intuitive dashboard for performing basic file CRUD operations — Create, Read, Update, and Delete — through a user-friendly web interface.

---

## ✨ Features

- 📄 Create new text files
- 👀 Read existing files
- ✏️ Rename files
- ➕ Append content to files
- 🔄 Overwrite file content
- 🗑️ Delete files safely
- 📥 Download file content
- 📊 Dashboard with file statistics
- 🎨 Modern and responsive Streamlit UI
- 🔐 Basic filename safety handling
- 📁 Dedicated workspace for managed files

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **pathlib**
- **Git & GitHub**
